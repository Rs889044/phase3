\section*{\centering{Instructions to Candidates}}

\begin{itemize}
    \item \textit{Please remove this section before submitting the rebuttal report. The submitted report should start from the next section.}
    \item This report documents the responses to the questions and comments provided by the examiners during the previous viva session. 
    \item This report is going to be assessed by a domain expert. Hence, the responses should be written in brief. \textit{Do not prepare a lengthy rebuttal report.}
    \item A response to a question or comment by an examiner documents how you wish to address the comment made by the examiner. 
    \item  All questions and/or comments made by the examiners should be addressed in this report. Each question/comment should be documented verbatim.  
    \item Response to a comment:
    \begin{enumerate} [label = (\alph*)]
        \item \textit{Scientific Response:} One part of the response provides a scientific argument or explanation as a response to the comment. You may refute the comment on various grounds. For example, it is possible that the examiner has misunderstood your work. In this case, you should provide an adequate scientific explanation of how or why you think your work has been misconstrued. To provide another example, suppose the comment is about changing your problem-solving approach. In this case, you can defend the original approach with suitable arguments. Otherwise, should you wish to incorporate changes in your thesis based on the comment, you can make suitable changes to your thesis as you deem fit. In this case, you need to provide a proper scientific justification for whatever changes you make in response to the comment.
        \item \textit{Documenting changes done in thesis in response to a comment:} If you made changes to your thesis in response to the reviewer's comment, you need to document the same in this report. It is possible that in response to a comment, changes are made in multiple places in the thesis. All such changes should be documented in the response to the comment. For a change made at a particular location, the page number and paragraph number(s) within each page, e.g. Page number 8, paragraphs 1-2, should be mentioned. If a particular change spans multiple pages continuously, then mention the page range and the relevant paragraph number in the starting page and the end page, e.g. Page number 8, paragraph 1 - Page number 9, paragraph 2.   
    \end{enumerate}
    \item Response to a question: 
    \begin{enumerate} [label = (\alph*)]
        \item You should answer the question from an examiner adequately, providing proper scientific justification. 
        \item If you make any changes to your thesis in response to a question from an examiner, document the same in this report.
    \end{enumerate}
    \item Any technical fact borrowed from the web, research papers, or other sources and used in responses to examiners should be supported with appropriate references.
    \item All literature cited in this document should be listed in the bibliography.
    \item This report should be written in formal language.
    \item Proofread the report for spelling and grammatical errors.
\end{itemize}
